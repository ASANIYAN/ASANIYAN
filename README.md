## 🚀 About Me

I'm a FullStack Engineer based in Lagos, Nigeria. I build interfaces for products where mistakes cost real money: fintech, healthtech, and online retail. I started as a Frontend Engineer and I'm now going deeper into backend systems, including databases, live data updates, and system design.

I treat every screen as a promise to the user. If a number is wrong, or a state is missing, that's not a small bug. It's broken trust.

---

## 💼 Experience

I've spent my career building frontend systems for products where the interface carries real weight: fintech dashboards handling live transaction data, healthtech tools running in clinics with unreliable internet, and online storefronts that are a business's main sales channel.

Across these roles, the pattern has stayed the same. Own the interface end to end. Build architecture other engineers can build on. Work closely with backend teams on workflows where a UI bug isn't cosmetic. It's a wrong balance, a missed prescription, a lost sale.

---

## 🎯 Where I'm Headed

I'm moving deeper into backend and infrastructure work: networking and protocols (TCP/IP, HTTP internals, DNS), live systems, and database design. My goal is to be an engineer who understands every layer of the stack, not just the one closest to the browser. That's what it takes to build systems that don't just work, but scale.

---

## 💡 Why It Matters

I build things people rely on with their data or their money. Understanding both the frontend and backend helps me catch problems earlier and build systems that hold up under real use.

I'm open to collaborating on fullstack or backend heavy projects.
